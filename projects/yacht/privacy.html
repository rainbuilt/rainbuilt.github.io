YACHT Privacy Policy

Effective date: June 10, 2026

YACHT is a Chrome extension that adds visual nested thread organization to ChatGPT conversations. This policy explains what data YACHT handles and how it is used.

YACHT is not affiliated with, endorsed by, or sponsored by OpenAI. ChatGPT is a trademark of OpenAI.

Data YACHT Stores Locally

YACHT stores visual thread state locally in the user's browser using Chrome storage. Stored data may include:

  • Selected source text used as visual thread anchors
  • Thread titles and thread IDs
  • Conversation-specific visual thread relationships
  • Anchor IDs and source turn references
  • Extension enabled status
  • Anchor color preference

How Data Is Used

YACHT uses this data only to provide its single purpose: visually organizing ChatGPT conversations into nested threads on chatgpt.com.

Data Sharing

YACHT does not transmit user conversation data to external servers. YACHT does not sell, rent, transfer, or share user data with third parties.

Remote Code

YACHT does not load or execute remote JavaScript or WebAssembly. All extension code is included in the extension package.

Network Requests

YACHT does not intercept network requests, modify OpenAI or ChatGPT API payloads, or send separate analytics requests.

Resetting Data

Users can reset YACHT data for the current ChatGPT conversation from the extension popup.

Contact

For support or privacy questions, please use the YACHT GitHub issues page.
