Privacy Policy

Last updated: September 19, 2026

This application is a personal OAuth client used solely by the owner to access Google Drive through rclone.

Information Accessed

The application may access Google Drive files and file metadata through Google OAuth 2.0, according to the permissions granted by the user.

Use of Information

Google Drive data is used only for personal file synchronization, backup, transfer, and file management through rclone.

Data Storage

This website does not collect or store Google Drive files, Google account information, or OAuth credentials.

OAuth tokens and rclone configuration are stored on the user's own device or system where rclone is installed.

Data Sharing

Google user data is not sold, rented, or shared with third parties by this application.

Data Retention

This website does not retain Google user data. OAuth access can be revoked at any time through the user's Google Account settings.
