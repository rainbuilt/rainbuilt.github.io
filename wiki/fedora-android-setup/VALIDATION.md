## 웹 문서

Chromium `144.0.7559.96`에서 화면과 동작을 확인했습니다. 검사 환경의 브라우저 정책이 로컬 파일과 HTTP 페이지 이동을 막아, 생성한 HTML과 CSS를 브라우저 문서에 넣고 같은 JS 파일 내용을 실행했습니다. 검사 범위는 로컬 파일의 표시와 동작입니다.

| --- | --- |
| 화면 너비 360, 390, 768, 1024, 1440, 1920 px | 문서 전체의 가로 넘침 없음 |
| 검색 | 복수 단어 검색, 결과 이동, 특수문자 입력 확인 |

WebGL 컨텍스트는 검사 브라우저에서 제공되지 않았습니다. 이때 CSS 3D로 전환되는 경로를 확인했습니다. WebGL의 메시와 셰이더 코드는 문법과 구조를 검토했습니다. 실제 GPU에서 WebGL 화면을 띄운 결과는 포함하지 않았습니다.

로컬 저장소의 실제 영구 저장과 운영체제 클립보드 내용은 일반 브라우저에서 한 번 더 확인해야 합니다. 검사에 사용한 메모리 대체 객체는 저장 로직을 확인하는 용도입니다. 실제 브라우저 저장 권한을 검증하지 않습니다.
